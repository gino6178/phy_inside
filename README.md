# phy_inside

From cut photographs to a physically interactive interior: a heterogeneous material field for
generated 3D solids.

- **Site (project analysis):** https://gino6178.github.io/phy_inside/
- `index.html` — the project page (teaser, abstract, architecture diagram, method, qualitative comparison, limitations, BibTeX).
- `analysis.html` — the full analysis: positioning, what was measured before building, the pipeline,
  results on the orange (photo classifier → NMFS neural material field → cut-force profiles → MPM
  cutting → drop test), the GaussianFluent comparison, limitations, experiment plan.
- `code/` — the pipeline scripts (Stage 1, Stage 2 baseline, NMFS, Stage 4, run comparison).
- `notes/` — the full plan with every correction recorded, and the discrete-inclusions measurement.
- `assets/` — every figure and gif on the site.

All numbers on the site are actual measurements from 2026-09-04; anything not yet run is marked as such.
